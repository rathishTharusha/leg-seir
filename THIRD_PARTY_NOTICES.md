# Rights and attribution

MIT covers the team's original software. It does not give permission to reuse every government report, population table, geographic/weather file, research paper or third-party code library. Each provider's terms still apply. The manuscript and dataset have their own applicable rights.

The public repository does not include third-party paper PDFs, lecturer files or bulk original source archives. Earlier reproduction notebooks download upstream code from its original repository at a fixed version. That downloaded code keeps its upstream license. A research citation is not a software license.

The dataset card and source manifest record providers, original file locations and source checks. Do not call the whole dataset MIT just because the project software uses MIT.
